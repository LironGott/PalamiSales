# palami.io: build and deploy

## Structure
| Path | What |
|---|---|
| `index.html`, `en/index.html` | Home page, Hebrew (RTL) and English (LTR). Written as page fragments so they can be previewed as a claude.ai artifact. |
| `privacy.html`, `accessibility.html` (+ `en/`) | Generated by `tools/legal.py` (edit the texts there, then run it from `site/`). |
| `css/site.css`, `js/site.js` | Shared by all pages. `site.js` holds the HE/EN strings for the product peek, form messages and menu. |
| `fonts/` | Self-hosted Rubik, Assistant, IBM Plex Mono (SIL OFL), Hebrew + Latin subsets. No request goes to Google. |
| `img/` | Images. Only the ones the pages use are copied to `dist/`. `og-he.png` / `og-en.png` are the share images (source in `tools/og/`). |
| `demo/index.html`, `css/lp.css`, `js/lp.js` | Landing page for agents and paid campaigns at `/demo/` (noindex, not in the sitemap). Ad links: `https://www.palami.io/demo/?for=agency&utm_source=facebook&utm_medium=paid&utm_campaign=...` (`for=solo|agency` tunes the headline area). |
| `tools/build.py` | Builds `dist/`, the folder that gets uploaded. |
| `dist/` | Ready-to-upload static site (~1.3 MB). |

## Build
```
python3 site/tools/legal.py        # only if the privacy / accessibility texts changed (run inside site/)
python3 site/tools/build.py        # writes site/dist/
FORM_ENDPOINT=https://... python3 site/tools/build.py   # same, with the demo form connected
python3 site/tools/build.py --preview                   # site/.preview/, for the artifact preview (not deployed)
```
The build adds `<!doctype>`, `lang`/`dir`, charset, viewport, canonical and hreflang links, Open Graph tags, favicon.ico, robots.txt, sitemap.xml and 404.html.

## Demo form
The form validates in the browser. Without `FORM_ENDPOINT` it shows a "design draft" message. With an endpoint it POSTs `name, email, phone, agency, lang` (multipart form data, `Accept: application/json`) and shows a thank-you message on any 2xx response. A hidden `website` field is a honeypot for bots.

## Measurement (no cookies, no banner)
Decision (2026-10-15): launch without an analytics tool. Measure with:
- **Form source.** Each demo request includes `source`: UTM tags from the landing URL (`source=…; medium=…; campaign=…`) and the referring site (`ref=linkedin.com`), or `direct`. Links you share should carry UTM tags, for example `https://palami.io/?utm_source=linkedin&utm_medium=post&utm_campaign=launch` or `?utm_source=email&utm_medium=outreach`.
- **Google Search Console** (free, verified by a DNS TXT record, no code on the site): search queries, impressions, clicks. Submit `sitemap.xml`.
- **Host metrics** (Amplify/CloudFront): basic request counts.
When paid campaigns start, consider Plausible (cookieless, no banner): one script tag, add its domain to the CSP and one line to the privacy policy.

## Hosting: AWS Amplify (approved 2026-10-15)
Decisions: AWS Amplify Hosting, Formspree for the form, domain palami.io registered at GoDaddy, mailbox info@palami.io.
DNS stays at GoDaddy (so the email records are untouched). GoDaddy cannot point the bare domain at Amplify, so **www.palami.io is the main address** and palami.io forwards to it (`SITE_URL` in `tools/build.py`). Moving DNS to Route 53 would allow the bare domain; then rebuild with `SITE_URL=https://palami.io`.

Launch runbook:
1. **Formspree:** sign up with info@palami.io, create a form, confirm the email, copy the endpoint `https://formspree.io/f/XXXXXXXX`.
2. **Build:** `FORM_ENDPOINT=https://formspree.io/f/XXXXXXXX python3 site/tools/build.py`, then zip the *contents* of `site/dist/` (index.html at the zip root).
3. **Amplify:** AWS console → Amplify → Create new app → Deploy without Git → upload the zip. Test on the temporary `*.amplifyapp.com` address.
4. **Amplify settings:**
   - Hosting → Custom headers: paste `amplify/custom-headers.yml` (security headers incl. CSP with formspree.io, cache rules).
   - Hosting → Rewrites and redirects: add the rule in `amplify/rewrites.json` (`/<*>` → `/404.html`, type 404).
5. **Domain (DNS change, only with approval):** Amplify → Custom domains → Add palami.io. Amplify lists a CNAME for `www` and a CNAME for certificate validation; add both in GoDaddy DNS. In GoDaddy, forward palami.io → `https://www.palami.io` (permanent 301). Do not touch MX/TXT email records.
6. **After launch:** test the form end to end (a submission must reach info@palami.io), verify Google Search Console with a DNS TXT record, submit `sitemap.xml`.

Later updates: rebuild, zip `dist/`, upload a new deployment in Amplify (or connect the GitHub repo with `site/dist` as the output folder and no build command).
